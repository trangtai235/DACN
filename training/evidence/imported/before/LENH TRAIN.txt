BA LENH CHINH XAC DA DUNG
-------------------------

  XLM-R base    (5 epoch, batch 16, lr 3e-5)
  ------------------------------------------------------------
  python code\train_vihos.py --variant syllable \
    --model xlm-roberta-base --epochs 5 --batch-size 16 --lr 3e-5 \
    --test --data-root datasets\ViHOS --out ket-qua\xlmr-base


  XLM-R large   (4 epoch, batch 8, lr 1e-5, grad-accum 2)
  ------------------------------------------------------------
  python code\train_vihos.py --variant syllable \
    --model xlm-roberta-large --epochs 4 --batch-size 8 --lr 1e-5 \
    --grad-accum 2 --test --data-root datasets\ViHOS --out ket-qua\xlmr-large


  PhoBERT base  (5 epoch, batch 32, lr 2e-5)
  ------------------------------------------------------------
  python code\train_vihos.py --variant syllable \
    --model vinai/phobert-base --epochs 5 --batch-size 32 --lr 2e-5 \
    --test --data-root datasets\ViHOS --out ket-qua\phobert-base


  (Dau \ la xuong dong. Tren Windows co the viet tat ca tren 1 dong.)
